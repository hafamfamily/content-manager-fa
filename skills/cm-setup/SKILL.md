# cm-setup — راه‌اندازی برند و اتصال سکوها

هیچ چیز مخصوص یک برند در کد نیست؛ همه در پوشهٔ همان برند است:
`<خانه>/brands/<brand>/{brand.md, brand.json, platforms.json, queue/}`.

## گام ۱. پیش‌نیاز و خانه (بی‌سروصدا)
```bash
python <مخزن>/engine/cm.py home            # جای فعلی
python <مخزن>/engine/cm.py home "E:/Claude/content"   # فقط اگر صاحب برند جای دیگری خواست
```
پایتون ۳.۱۰ به بالا. ffmpeg برای ویدیو. فقط اگر چیزی کم بود بگو.

## گام ۲. برند
`python cm.py brand new <slug>` (حروف کوچک انگلیسی و خط تیره). بعد مصاحبهٔ کوتاه برای پر کردن
`brand.md`: **چند نوبت ۳ تا ۴ سؤالی**، نه فرم بلند. هر چه را از قبل می‌دانی دوباره نپرس؛ جایی که
مطمئن نیست دو سه گزینهٔ مشخص بده. نوبت‌ها: پایه و سکوها ← مخاطب ← هدف و CTA ← ستون‌ها ← لحن ←
منابع معتبر ← خطوط قرمز. `brand.json`: نام، نام کاربری، سایت، رنگ‌ها، امضای پایان پست هر سکو.

## گام ۳. سکوها — فقط با رضایت صریح
فهرست ۸ سکو را با قابلیت واقعی هر کدام نشان بده و بپرس کدام‌ها:

| سکو | روش | انتشار خودکار | آمار |
|---|---|---|---|
| تلگرام | ربات رسمی (BotFather) | ✅ | ❌ از API |
| بله | ربات رسمی (BotFather بله) | ✅ | ❌ |
| ایتا | ایتایار | ✅ (connector در راه) | بازدید (باید آزموده شود) |
| روبیکا | Bot API نسخهٔ ۳ | ✅ (connector در راه؛ ارسال به کانال باید آزموده شود) | ❌ |
| روبینو | API ندارد | ❌ بستهٔ آماده، انتشار دستی | ❌ |
| اینستاگرام | Graph API رسمی | ✅ پس از راه‌اندازی اپ متا | ✅ |
| یوتیوب | Data API رسمی | ✅ | ✅ |
| آپارات | API قدیمی | ⚠️ تجربی | ❌ |

برای هر سکوی انتخاب‌شده در `platforms.json`: `enabled: true`، `method: api|manual`، `chat_id`
(مثلاً `@channel`)، و نام توکن در `secret`.

## گام ۴. توکن — هرگز در گفتگو
صاحب برند خودش در PowerShell روی کامپیوتر خودش می‌زند (مقدار دیده نمی‌شود و با DPAPI ویندوز رمز
می‌شود):
```bash
python cm.py secret set <brand> telegram_token
```
اگر توکن را در گفتگو فرستاد، استفاده نکن؛ بگو پیام را پاک و توکن را باطل کند و دوباره بسازد.

## گام ۵. آزمایش واقعی
```bash
python cm.py platform test <brand> telegram     # ربات، کانال، مدیر بودن ربات؛ چیزی ارسال نمی‌شود
```
فقط وقتی `OK` گرفت آن سکو را «وصل» اعلام کن. هیچ اتصالی را بدون آزمایش موفق، موفق گزارش نکن.

## گام ۶. زمان‌بند و بیدار ماندن
`platforms.json` ← `"awake": {"from": "06:00", "to": "15:00"}` بازه‌ای که لپ‌تاپ نباید بخوابد.
```bash
python cm.py schedule            # نمایش؛ بعد از تأیید صاحب برند:
python cm.py schedule --apply    # هر ۱۵ دقیقه انتشار + بیدار ماندن روزانه
```
بگو: بستن درِ لپ‌تاپ طبق تنظیم ویندوز آن را می‌خواباند؛ اگر می‌خواهد در بسته هم کار کند، خودش از
Control Panel ← Power Options ← «Choose what closing the lid does» گزینهٔ «Do nothing» را برای حالت
وصل به برق انتخاب کند. این تنظیم سیستم را خودت عوض نکن.
