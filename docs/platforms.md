# سکوها: چه چیزی واقعاً کار می‌کند

نتیجهٔ آزمایش روی کانال‌های واقعی صاحب برند (آبان ۱۴۰۵). هر چیزی که آزموده نشده، صریحاً «آزموده نشده» است.

## روش انتشار

| سکو | روش در cm | وضعیت |
|---|---|---|
| تلگرام | Bot API رسمی | ✅ خودکار؛ متن، عکس، آلبوم، ویدیو |
| بله | Bot API رسمی (سازگار با تلگرام) | ✅ خودکار |
| ایتا | EitaaYar API (`eitaayar.ir/api/<token>/sendMessage|sendFile`)، شناسهٔ عددی کانال | ✅ خودکار؛ فقط متن ساده |
| روبیکا | Bot API نسخهٔ ۳ (`botapi.rubika.ir/v3/<token>/...`)، ارسال فایل: requestSendFile ← آپلود ← sendFile | ✅ خودکار؛ تک‌فایل. آلبوم چندعکسی از API ممکن نیست؛ فقط دستی در اپ یا وب |
| روبینو | API ندارد | 📦 بستهٔ دستی (`cm package`) |
| اینستاگرام | Graph API رسمی (از لایهٔ Claude با Composio) | ⚠️ وابسته به اتصال؛ موتور خودکار ندارد → بستهٔ دستی |
| یوتیوب | Data API (از لایهٔ Claude با Composio) | ⚠️ سهمیهٔ روزانهٔ اپ مشترک ممکن است تمام شود؛ فایل باید در فضای Composio باشد. پروژهٔ شخصی گوگل کلود تأییدنشده ویدیو را «خصوصی» قفل می‌کند. → بستهٔ دستی |
| آپارات | API قدیمی (پاسخ 503 در آزمایش) | 📦 بستهٔ دستی؛ یا صفحهٔ بارگذاری در مرورگر با انتخاب فایل توسط خود صاحب برند |

## قالب متن (منبع: `html`)

| | بولد | کج | زیرخط | خط‌خورده | نقل‌قول | لینک پشت کلمه |
|---|---|---|---|---|---|---|
| تلگرام (HTML) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| بله (Markdown) | ✅ `*...*` | ❌ | ❌ | ❌ | ❌ | ✅ `[متن](آدرس)` |
| روبیکا (metadata، اندیس UTF-16) | ✅ | ❌ | ✅ | ✅ | ❌ | ✅ |
| ایتا (EitaaYar) | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ (فقط متن کلمه می‌ماند) |
| بستهٔ دستی | متن ساده؛ آدرس‌ها حذف و متن کلمه‌ها نگه داشته می‌شود |

`engine/cmlib/formats.py` همین جدول را اجرا می‌کند؛ آنچه نمایش داده نمی‌شود حذف می‌شود تا علامت خام نماند.

## نکته‌های عملی
- **آدرس خام ممنوع:** چک فنی `cm add` متنی را که آدرس بیرون از `<a>` دارد رد می‌کند.
- **هر پست با تصویر یا ویدیو:** با `"require_media": true` در `platforms.json`.
- **ویرایش پست قدیمی تلگرام:** با `editMessageText/editMessageCaption` و جابه‌جا کردن offset موجودیت‌ها ممکن است؛
  بله و روبیکا ویرایش قابل اتکا ندارند: پست تازه، و پاک کردن قدیمی با خود صاحب برند.
- **مرورگر داخلی اپ Claude** نمی‌تواند فایل محلی را خودش در فرم سایت بگذارد؛ انتخاب فایل با صاحب برند است
  و پر کردن عنوان، توضیحات، برچسب و انتشار با Claude.
- **پاک کردن پیام‌ها** همیشه با خود صاحب برند است.
