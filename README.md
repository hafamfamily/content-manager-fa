# content-manager-fa

مدیریت یکپارچهٔ محتوای فارسی در ۸ سکو، برای **هر برند و هر موضوع**.

- **لایهٔ هوش (Claude):** تحقیق، تولید محتوای چندقالبی، کپشن مخصوص هر سکو، کنترل کیفیت، پرسیدن اجازه.
- **موتور اجرایی (`engine/cm.py`):** بدون Claude روی کامپیوتر صاحب برند اجرا می‌شود؛ فقط محتوای
  تأییدشده را سر ساعت منتشر می‌کند، تلاش مجدد، دفتر انتشار، گزارش، کلید توقف.
- **رابط بین دو لایه:** پوشهٔ بسته (`item.json` + فایل‌ها) و پایگاه SQLite.

> وضعیت: نسخهٔ 0.1 — هستهٔ موتور، تلگرام و بله. ایتا، روبیکا، اینستاگرام، یوتیوب در مراحل بعد.
> قابلیت‌های پیاده‌نشده در جدول «سکوها» در `skills/cm-setup/SKILL.md` صریح نوشته شده‌اند.

## شروع سریع (ویندوز)
```powershell
python engine\cm.py home "E:\Claude\content"
python engine\cm.py brand new my-brand
python engine\cm.py secret set my-brand telegram_token     # مقدار در ترمینال، رمزشده با DPAPI
python engine\cm.py platform test my-brand telegram
python engine\cm.py schedule --apply
```

## ایمنی
- هیچ چیز بدون تأیید صریح صاحب برند منتشر نمی‌شود؛ تأیید به هش محتوا بسته است.
- توکن‌ها با DPAPI ویندوز رمز می‌شوند و هرگز چاپ یا در گیت ذخیره نمی‌شوند (`.gitignore`).
- `cm stop` همه‌چیز را فوراً متوقف می‌کند.
- فقط API رسمی هر سکو؛ نه ربات مرورگری، نه سلف‌بات.

## تست
```bash
python tests/run.py     # بدون اینترنت و بدون توکن واقعی
```
